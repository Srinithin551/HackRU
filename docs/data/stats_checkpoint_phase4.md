## Recommendation

- **Keep the PLAN.md constants for now** (HR 25%, BR 40%, focus 0.5). On this data calm stays at 3 (p95 7), far under 40, and every spike crosses 70, so nothing needs fixing before Integration 1.
- **Tune with real Presage data, not mock data.** Presage's HR noise will be larger than the mock's ±2 bpm. If real calm p95 comes out above ~25, raise `HR_MAX_PCT` (30 halves the HR noise contribution relative to 15); if a real stressor (mental math) stays under 40, lower it toward 20.
- sensing.md's jumping-jacks result is the 'stress 100' reference: set `HR_MAX_PCT` near the HR rise measured there, then check calm p95 with this script.
- Thresholds (40/70) and the 0 to 100 scale are fixed by PLAN.md; only the constants move.
